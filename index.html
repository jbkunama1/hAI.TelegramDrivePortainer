Wie es funktioniert

Die Tauri-Desktop-App laeuft headless unter Xvfb + Fluxbox, per x11vnc/noVNC im Browser erreichbar. Die REST-API der App bindet bewusst nur auf 127.0.0.1 – ein socat-Proxy exponiert sie kontrolliert nach aussen. Der Container wird bei jedem Push per GitHub Actions gebaut und nach ghcr.io/jbkunama1/hai.telegramdriveportainer gepusht.
